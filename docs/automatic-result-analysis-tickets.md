# Automatic result analysis tickets

Published from the approved 21-ticket breakdown using the to-tickets skill. Every automatic report analyzes only the latest completed iteration, once after each successful run.

The source is the local implementation spec; no parent issue was created or modified. Ticket 1 is the initial implementation frontier.
